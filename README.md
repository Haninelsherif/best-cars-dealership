# Best Cars Dealership

Full Stack Application Development Capstone — Best Cars Dealership.

## Project
A dealership review application built with Django/React. It provides authentication, dealer browsing, dealer reviews, car makes/models, state filtering, and review sentiment analysis.

## Required project areas
- Django backend under server/
- React frontend under server/frontend/
- Static About and Contact pages
- REST endpoints for dealers, reviews, car makes, authentication, and sentiment analysis
- GitHub Actions CI/CD workflow
